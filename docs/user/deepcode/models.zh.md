# 模型与视觉

[English](models.md) | 中文

DeepCode 直接使用 Harness 的模型与凭据服务。在**设置 → 模型**中完成配置后，DeepCode 会直接使用该模型，不会再维护第二份提供方文件或凭据存储。

## 配置 DeepSeek

1. 打开**设置 → 模型**。
2. 选择 DeepSeek 提供方。
3. 输入 DeepSeek API key。
4. 页面提供获取或刷新模型操作时，执行该操作。
5. 选择本次会话要使用的模型。

API key 缺失、无效、过期，或无权使用所选模型时，提供方可能拒绝请求。DeepCode 会报告失败，但不会把 key 复制进诊断信息。

## 使用图片输入

选择输入模态包含图片的模型，例如你的账户可用 `deepseek-v4-flash-vision-exp` 时可以选择它。在消息中附加图片，写清楚要求，然后像普通提示词一样发送。

支持图片的模型可以检查截图、图表、UI 状态与其他视觉输入。纯文本模型无法推断附件内容；要求模型分析图片前，请先切换模型。

## 添加自定义提供方

需要 OpenAI-compatible endpoint（OpenAI 兼容端点）或 Harness 设置页面支持的其他提供方时，请使用自定义提供方表单。只填写该提供方要求的值：

- 提供方名称与 base URL。
- API key 或凭据（如果需要）。
- 模型 id。
- 输入能力；端点支持图片时包含图片输入。

不要把纯文本端点标记成支持图片。模型选择器会根据这些元数据判断附件能否发送给模型。

## 切换模型

当前模型属于 Harness 会话。在对话界面的模型选择器中切换模型。已有消息仍保留在会话中；下一个模型会收到 Harness 为下一轮准备的上下文。

## 故障排查

### 模型列表中没有需要的模型

刷新提供方的模型列表。使用自定义端点时，请添加提供方给出的准确模型 id。不同账户与地区可用的模型可能不同。

### 会话报告缺少凭据

返回**设置 → 模型**，为当前会话使用的同一提供方路由保存 key。为一个自定义提供方保存的 key 不会授权另一条路由。

### 模型看不到附加的图片

确认所选模型声明支持图片输入，而且端点本身接受 OpenAI-compatible `image_url` 内容。然后用一张图片和一个直接问题开始小规模测试。
